# ToDo の書き方と通知（使い方）

ToDo パネルの入力欄と、通知（リマインド）のしくみをまとめたものです。

## 入力欄に一行で書く

ToDo パネル上部の入力欄では、やることの後ろに記号を付けると、
期限や優先度をその場で決められます。Enter で追加、入力欄は空に戻るので続けて打てます。

```
資料作成 @明日 !高 #開発 ~30m *前日
```

これで「資料作成」という ToDo が、期限=明日・優先度=高・カテゴリ=開発・
見積もり=30分・通知=期限の前日 で追加されます。

| 記号 | 決めるもの | 書き方の例 |
| --- | --- | --- |
| `@` | 期限 | `@今日` `@明日` `@明後日` `@金` `@来週` `@今週末` `@来月` `@8/12` `@2026/8/12` `@+3` `@+2w` |
| `!` | 優先度 | `!高` `!低` `!標準` |
| `#` | カテゴリ | `#開発`（カテゴリ名の先頭一致でよい） |
| `~` | 見積もり | `~30m` `~30分` `~90` `~1.5h` `~2時間` `~1時間30分` |
| `*` | 通知 | `*9:00` `*当日18:00` `*前日` `*3日前9:00` `*明日9:00` `*8/12 9:00`（`*8/129:00` と続けても可） |

補足:

- `@金` のような曜日は「次に来るその曜日」です。今日が金曜なら来週の金曜になります。
- `@+3` は3日後、`@+2w` は2週間後です。
- `@8/12` は今年の日付として読みます。半年以上前になる場合だけ来年に送ります。
- **記号の前には空白を入れてください**（行頭ならそのままで可）。
  後ろは続けて書けるので `@明日資料をまとめる` は「期限=明日／資料をまとめる」になります。
  前に空白を求めるのは、`9時~10時 打ち合わせ` の `~` が見積もりに化けないようにするためです。
- `*` で時刻を省略すると、設定の「既定の通知時刻」（初期値 9時）を使います。
- `*当日` `*前日` `*N日前` は**期限からの相対**です。あとで期限を動かすと通知も一緒に動きます。
  期限が無いときは相対の基準が無いので、その日の指定として扱います。
- 全角の記号（`＠！＃〜＊`）でもそのまま使えます。日本語入力を切り替える必要はありません。

### 記法が効かないとき

**解釈できなかった記号は、そのまま本文に残ります。**

- `#1 の対応` … `1` に一致するカテゴリが無いので、`#1` は本文のまま
- `@会議室で相談` … `会議室` は日付として読めないので、`@会議室` は本文のまま
- `終わった!` … `!` の後ろが優先度でないので、本文のまま

入力中は欄の下に**解釈結果**が出ます。Enter を押す前に、何が付くのか・
記号が本文として残るのかがそこで分かります。

記法そのものを使いたくない場合は、設定の「ToDo → 入力欄で記法を使う」を外してください。
外すと入力した文字がそのままタイトルになります。

## 通知（リマインド）

期限は日付しか持たないので、「いつ思い出したいか」は通知として別に決めます。
期限の数日前に一度だけ知らせる、といった使い方ができます。

### タイミングの決め方

編集ダイアログの「通知する」にチェックを入れると、タイミングを選べます。

| タイミング | 意味 |
| --- | --- |
| 日時を指定 | 決まった日時に一度だけ通知します |
| 期限の当日／前日／2日前／3日前／1週間前 | 期限からの相対で通知します |

相対にしておくと、**期限を動かしたときに通知も一緒に動きます。**
日時を指定した場合は動かないので、期限を延ばすたびに通知を付け直すことになります。

時刻は相対でも自分で決められます（「期限の前日 18:00」など）。

### 通知が出たら

画面上部にバナーが出ます。アプリを見ていないときはトレイ通知でも知らせます。

| ボタン | すること |
| --- | --- |
| 記録開始 | その ToDo のタイトル・色で記録を始めます |
| 完了 | 完了にします（通知も消えます） |
| ○分後 | 設定した時間だけ先送りします |
| ▾ | 5分後・15分後・30分後・1時間後・3時間後・明日の朝 から選んで先送りします |
| ✕ | この通知だけ閉じます（ToDo は残ります） |

先送りすると相対指定は外れます。「期限の前日9時」は約束なので、
一度先送りした時点でその約束から離れる、という考え方です。

### 見逃した通知

通知時刻から**15分以上**遅れて気づいた通知は、個別のバナーにはしません。
アプリを閉じている間に溜まった通知が、起動した瞬間に画面を埋めてしまうためです。

代わりに「通知時刻を過ぎた ToDo が N 件あります」と1本にまとめて出します。
「確認する」を押すと ToDo パネルが開き、見逃した1件目が選ばれます。

拾うのは**直近3日以内**の通知だけです。それより古いものは出しません
（期限を過ぎていること自体は一覧の色と1日1回のまとめ通知で分かるため）。

### 1日1回のまとめ通知

個別の通知を付け忘れていても、その日に片付ける量が一度は目に入るように、
1日1回「今日が期限」「期限超過」の件数をまとめて知らせます。
時刻は設定で変えられます（初期値 9時）。対象が0件の日は通知しません。

## 退勤時のふりかえり

退勤（ツールバーのボタン、Ctrl+Alt+E、トレイメニュー）を押すと、その日を締める画面が出ます。

上半分は今日の実績です。

- 勤務時間と、出勤〜退勤の時刻
- 記録した時間と、勤務時間に対する割合
- 完了した ToDo の件数

下半分は**明日へ送る候補**です。未完了のうち、次のものが並びます。

| 並ぶもの | 理由の表示 |
| --- | --- |
| 今日やると決めたもの | 今日やる |
| 期限を過ぎているもの | 期限 N日超過 |
| 期限が今日のもの | 期限が今日 |

それぞれに「今日 1:20 記録」か「手つかず」が付きます。決めたのに一度も触らなかったのか、
着手はしたが終わらなかったのかで、明日へ送るかどうかの判断が変わるためです。

既定では全部にチェックが入っています。そのまま Enter で確定できます。
**送るのは「今日やる」の印だけで、期限は変わりません**（期限は約束、今日やるは計画なので、
動かしてよい方が違います）。Ctrl+Z で元に戻せます。

### なぜ退勤時なのか

「今日やる」は日付で持っているため、日をまたげば自動的に外れます。狙いどおりの挙動ですが、
そのままだと**手を付けなかったものが黙って消えます**。決めたのにやらなかった、という事実が残りません。

退勤は1日の中で唯一「終わり」がはっきりしている操作なので、そこで一度だけ確認します。

出す条件と出さない条件:

- 候補も実績（記録時間・完了した ToDo）も無い日は出しません。手を止めるだけになるためです
- 日付をまたいで自動的に締めた退勤では出しません。本人が画面を見ていないときに出しても、
  明日へ送る判断ができないためです
- 設定パネルの「勤務の記録」→「退勤時にふりかえる」で切れます

## 設定

設定パネルの「ToDo」にまとまっています（退勤時のふりかえりだけは「勤務の記録」にあります）。

| 設定 | 内容 |
| --- | --- |
| 入力欄で記法を使う | `@ ! # ~ *` を解釈するかどうか |
| 既定の通知時刻 | 通知の時刻を省略したときに使う時 |
| 「あとで」の時間 | バナーのボタンに出る先送りの時間（▾ から他の時間も選べます） |
| 通知音を鳴らす | 通知バナーが出たときに音を鳴らすか |
| まとめて通知する／通知する時刻 | 1日1回のまとめ通知 |
| 完了済みを残す期間 | この期間を過ぎた完了済みをアーカイブへ移す |
