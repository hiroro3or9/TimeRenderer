# 10. 記録・離席検知・出退勤

この3つは別々の軸です。**記録**は「いま何をしているか」を測るタイマー、**離席検知**はその記録から抜くべき時間を見つける仕組み、**出退勤**は1日の始まりと終わりの打刻です。混ぜないでください。

## 記録

開始の入口は4つあります。ツールバーのボタン（ダイアログでタイトル・タイマー・プロジェクトコードを選ぶ）、トレイやホットキー（ダイアログなしで「作業ログ 14:05」のような既定タイトルで即開始）、予定から開始（予定のタイトル・色・カテゴリ・プロジェクトコードを引き継ぐ）、ToDo から開始。

記録中は、タイトル・経過時間・色・カテゴリ・プロジェクトコード・「元になった予定」「紐づく ToDo」をセッション情報として持ちます。タイマー（カウントダウン）を選んでいれば、0になった時点で自動停止します。

停止したときの処理がこの機能の中心です。

1. 停止時刻を確定し、タイトルが空なら既定のタイトルにする
2. **セッションをリセットする前に**離席の記録を取り出す
3. 次の記録を続けて始める指定があれば、ここで始める（確認ダイアログの待ち時間を次の計測に含めないため）
4. 離席をどう扱うかに応じて、記録を1つ以上の区間に分ける
5. 区間ごとに実績を作り、ToDo に時間を積算し、まとめて1件の履歴に積む

区間の1つ目に「元になった予定」があるときは、新しい実績を作らず**その予定を実績に変えます**。予定が1つ消えて実績が1つ増える、という見た目にしたいからです（内容欄が空なら「記録時間: 1:30」を書き入れます）。2つ目以降は新しい実績として作り、どれも元の予定の Id を持たせておきます。

全体が離席だった場合は何も記録せず、その旨を通知します。

## 離席検知

3つの経路で拾います。

- **無操作**：システム全体の最終入力時刻を5秒ごとに見る（他のアプリを操作している間も拾えます）
- **スリープ**：電源イベント。ティックカウントはスリープ中に進まないので、無操作の判定だけでは足りません
- **画面ロック**：セッション切り替えイベント。理由を「ロック」と出し分けられます

閾値（既定10分）を超えた離席だけを通知します。復帰した瞬間の判定には「実際の無操作時間ぶん遡った時刻」を使い、閾値ぶんだけ遡る雑な計算はしません。スリープから復帰した直後は、大きな無操作時間を二重に数えないよう状態をリセットします。

記録中に離席が始まったら、画面上部に「14:20 から操作がありません。記録は続いています（停止時に除外できます）」というバナーを出します。**その場では何もしません**。記録中に自動で削ると、実際は作業していた（動画を見ていた、紙で作業していた）ときに取り返しがつかないからです。

停止時の扱いは設定で3つから選べます。毎回確認する（既定）、常に除外する、常にそのまま記録する。確認ダイアログでは、検知した離席の一覧と「除くと実作業は何分になるか」「記録が複数に分割されること」を見せてから聞きます。自動で除外した場合も、何件・合計何分を除いたかを通知し、Ctrl+Z でその記録ごと取り消せるようにします。

ポーリングの取りこぼしを防ぐため、記録を停止する直前に「いま進行中の離席」を確定させる処理を1回挟みます。逆に、記録を開始するときは溜まっていた離席を破棄します。

## 出退勤

出勤と退勤を打刻し、日/週ビューに横線として出します。未退勤の記録は同時に1件だけです。

方針は「**勝手に確定するのは日付が変わった場合だけ**」。当日中の離席やスリープでは、確認してから確定します。

- **自動で締める**：記録中でなく、出勤日が今日より前のまま未退勤なら、その日の最後の実績の終了時刻で締めます。実績が無ければ出勤時刻のまま（勤務時間を水増ししない）。締めたことは通知し、マーカーにも「（自動）」と出します
- **確認して締める**：勤務終了検知が有効なら、閾値（既定30分）以上の離席から戻ったときに「17:32 を退勤時刻として記録しますか？」と聞きます。日中の会議や外出で毎回聞かれないよう、「17時以降に始まった離席だけ確認する」という下限を設定できます。ただし日付をまたいで戻ったときは時間帯に関係なく聞きます

押し忘れた日は、出退勤ボタンの右クリックか、日/週ビューの線のラベルから編集ダイアログを開いて追加・修正できます。時刻は「9:05」「905」のような入力を受け付け、退勤が出勤より前なら翌日として扱い、24時間を超えたらエラーにします。同じ日に再び出勤を押したときは、新しい記録を作らず**その日の記録を再開**します（1日に何本も線が並ばないように）。

勤務記録には「その日のひとこと」も付きます（`06` のふりかえり一覧と統計で読み返します）。

## 退勤時のふりかえり

退勤したときに一度だけ出すダイアログです。自動で締めた退勤では出しません。

出す内容は3つ。**今日の数字**（勤務時間、記録した時間とその割合、完了した ToDo の件数）、**今日のひとこと**（任意。git のリポジトリを登録していればその日のコミット一覧も出し、「ひとことへ貼る」で流し込めます）、そして**片付かなかった ToDo**です。

繰り越しの候補は「今日やる印が付いていたもの」と「期限が今日以前のもの」。それぞれに理由（「今日やる」「期限が今日」「期限 2日超過」）と、その日その ToDo で記録した時間（無ければ「手つかず」）を添えます。チェックを外せるようにして、「N 件を明日へ」を押すと**今日やる印だけを明日へ移します。期限は変えません**。全部片付いている日は、空のリストではなくその旨を出します。

一言はどの閉じ方をしても保存します（閉じるボタンで消えると書く気がなくなります）。繰り越しは1件の履歴に積むので、Ctrl+Z で戻せます。
