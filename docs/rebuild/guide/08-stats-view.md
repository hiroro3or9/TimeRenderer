# 08. 統計と月次タイムシート

## 何を集計するか

集計対象は**実績だけ**で、終日のものは除きます。予定を混ぜると「やる予定だった時間」と「やった時間」が足し合わされて意味が無くなり、終日の予定は時間ではないからです。

期間は週・月・スプリントの3つから選びます。週は月曜始まり、月は暦月、スプリントは手動または自動で区切られた期間です。期間をまたぐアイテムは**期間の端で切って**から数えます。

## 集計の中身

基礎の集計は純粋関数にまとめ、次を一度に作ります。

- カテゴリ別の合計
- プロジェクトコード別の合計
- 日別×カテゴリ、日別×プロジェクトコードの合計
- 件数

日をまたぐアイテムは日ごとに按分します。カテゴリが解決できないものは「未分類」として色ごとにまとめ、プロジェクトコードが無いものは「（未設定）」、マスターに無い Id は「（不明なプロジェクトコード）」として残します。**消さずに見せる**のが要点で、消すと合計が合わずに混乱します。

並び順はマスターの登録順を優先し、マスターに無いもの（未分類・未設定・不明）は時間の多い順で後ろに付けます。

## 画面の構成

上に期間のセグメントと合計（「合計 7:30 ／ 12 件」）。その下に、期間内のふりかえり（書いた一言のカード。押すとその日の勤務記録の編集が開く）を置きます。記録が0時間の期間でも読み返せるよう、**実績の有無とは独立して**出します。

続いてプロジェクトコード別の横棒、月のときだけ月次タイムシート、カテゴリ別の横棒、最後に日別の積み上げ棒グラフです。

日別のグラフは、棒の高さの上限を決め、最大の日を基準に正規化します。0に近い値でも最低2pxは描いて「あったこと」が見えるようにします。積む順序はカテゴリの表示順の逆（先頭のカテゴリが一番下）、日付ラベルは期間が2週間を超えたら日付だけに短縮し、今日は色を変えます。

## 月次タイムシート

勤怠システムへ手で転記するための表です。縦がプロジェクトコード、横が1日から月末まで、値は **15分単位に丸めた時間**。

丸め方が要点で、**日・コード単位で合算してから丸めます**。個々の記録を先に丸めると、細切れの記録が多い日に誤差が積み上がります。丸めは 0.5 を切り上げ側に倒します。

セルをクリックすると丸めた値（`1.25` のような小数）がクリップボードに入り、行の見出しを押すとプロジェクトコードがコピーされます。コピーしたことを画面の上に短く出します。ツールチップには「実績 1:20 → 15分単位 1.25h」のように元の値と丸めた値を両方出して、転記した数字が信用できるようにします。

行の見出しはコードを主、名前を従で出し、無効化されたコードには「（無効）」、コードが未入力・未設定・不明のものには警告色を付けます。最下行に日別合計、右端に月合計を置きます。

## 未記録時間の加算（任意）

設定を有効にすると、**勤務時間のうち実績で覆われていない時間**をプロジェクトコード別の統計と月次表にだけ足せます。カテゴリ別と日別グラフには足しません（あちらは「何をしていたか」の集計なので、正体不明の時間を混ぜられない）。

加算先は期間で切り替えられます。「この日からこのコード」という行を並べるだけの持ち方にして、期間の終わりは次の行の開始日から導きます。こうすると隙間も重複も原理的に起きません。未記録時間は日ごとに割ってから日単位で加算先を解決するので、集計期間が割り当てをまたいでも正しく分かれます。
