# 04. メインウィンドウ

## 画面の骨格

ウィンドウは縦4段です。上からツールバー、ビュー切り替えのナビゲーション、作業領域、そして作業領域に重なる通知とパネル。作業領域には全ビュー（今日・日/週・月・スプリント・タイムライン・統計・ふりかえり）を置き、表示モードに応じて1つだけ見せます。

**見えていないビューは Collapsed にします**。以前は「月以外は生きたまま」だったため、見えないビューのレイアウト計算と描画にコストを払い続けていました。

右端には設定パネル・管理パネル・ToDo パネルをオーバーレイで重ねます。作業領域を押し縮めないので、パネルを開いても予定の配置が動きません。

## ツールバー

左から、日付の前後移動と「今日」、中央に検索、右に操作系を並べます。操作系は多く、左から順に「表示フィルタ」「出勤/退勤」「記録タイトル入力」「記録の開始/停止」「ToDo」「管理」「設定」です。

記録ボタンは**幅を固定**し、中の文字だけを「● 記録開始」「■ 停止 (00:12:34)」と切り替えます。幅が変わると押そうとした瞬間にボタンが動いてしまいます。記録中は赤い塗り、ホバーでさらに濃く。

ウィンドウ幅が足りなくなったら、ツールバーを**2段に組み替えます**。バインディングでは表現しづらいので、コードビハインドで実測して切り替えます。閾値の前後で行き来してちらつかないよう、戻す側の閾値を少し広く取ってください。

検索ボックスは、フォーカスすると下に結果のフライアウトが開きます。結果は予定・ToDo・ふりかえりが混ざった1つの一覧で、選ぶとその日付へ飛んで対象を選択します。表示フィルタはポップアップで、カテゴリとプロジェクトコードのチェックボックスを出します（この絞り込みは保存しません）。

ポップアップを閉じた直後にボタンを押すと「閉じる → すぐ開く」になってしまうので、閉じた時刻を覚えておいて 250ms 以内のクリックは無視します。

## ビューのナビゲーション

ツールバーの下に、全表示モードを常時見せる行を置きます。「今日 / 日 / 週」「月 / スプリント / タイムライン」「統計 / ふりかえり」のように意味でグループ化し、間に細い区切りを入れます。ドロップダウンにしないのは、切り替えが頻繁で、今どこにいるかが常に見えているほうが迷わないからです。

## パネルの排他

設定・管理・ToDo の3つのパネルは同時に開きません。どれかを開くと他は閉じます。幅は 0.15 秒で伸縮させ、閉じているときは幅0にします（レイアウト上の場所も取らない）。

## 通知の出し方

通知は作業領域の上に重ね、**作業領域を押し下げません**。押し下げると通知が出たり消えたりするたびに予定の位置が動きます。

通知には2種類あります。

- **継続表示**：データの読み込みに失敗したときの警告。閉じられず、そのセッションの間ずっと出ます
- **一時表示**：定期予定のリマインダー、ToDo の通知、見逃した通知のまとめ、朝のまとめ、自動開始や自動保存のお知らせ、離席中のバナー

一時表示のカードは、種類ごとに色を変えて（リマインダーは青系、ToDo は黄系、注意は赤系）、その場で次の行動が取れるボタンを置きます。ToDo の通知なら「記録開始」「完了」「あとで」、リマインダーなら「記録開始」。「あとで」の横の小さな矢印を押すと、5分後・15分後・30分後・1時間後・3時間後・明日の朝から選べます。

自動的に何かをしたときのお知らせ（記録を自動開始した、離席分を除いた、ToDo を明日へ送った、など）は **6秒で自動的に消えます**。押さなくても消えるものと、押さないと消えないものを混ぜないでください。

## タスクトレイ

トレイアイコンは、出勤中・記録中の状態を重ねて描き分けます。ホバーしたときの文字列も「TimeRenderer - 出勤中・記録中 (00:12:34)」のように状態と経過時間を出します。カウントダウン中なら残り時間です。

右クリックメニューは、開く/表示、記録の開始・停止（ホットキーがあれば併記）、出勤・退勤、区切り、終了。メニュー項目の文字はアプリの状態に合わせて毎回作り直します。

最小化するとタスクバーから消してトレイに入り、閉じるボタンも同じ扱いにします（記録を続けたまま邪魔にならないように）。本当に終了するのはトレイメニューの「終了」だけで、そのときは記録中なら停止して保存します。

非アクティブのときにリマインダーが届いたら、バルーン通知も出します。

## グローバルホットキー

ウィンドウが前面に無くても効くホットキーを4つ登録します。記録の開始/停止、出勤、退勤、ウィンドウの表示です。他のアプリと衝突する可能性があるので、**第1候補が取れなければ第2・第3候補へフォールバック**し、実際に登録できた組み合わせをボタンのツールチップとトレイメニューに出します。どれも取れなかったときは黙って諦めます（起動を止めない）。

## ミニ記録バー

記録中だけ、タイトルと経過時間を出す小さなバーを最前面に浮かべます。他のアプリで作業している間も、何を記録中かが見えるようにするためです。

このウィンドウには3つの条件があります。**Alt+Tab に出さない**、**クリックしても入力フォーカスを奪わない**、**タスクバーに出さない**。ウィンドウスタイルの拡張フラグで実現します。ドラッグで好きな場所へ動かせて、位置は設定に保存し、次回も同じ場所に出します。画面外に行かないよう、表示時に作業領域内へ収めます。

ドラッグとクリックの区別は移動量で行います。2px 以上動いたらドラッグ、それ未満ならクリック（＝メインウィンドウを前面に出す）です。
