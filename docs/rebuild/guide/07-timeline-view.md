# 07. スプリントタイムライン

## 何が違う画面か

日/週ビューが「1日の中の時間」を見る画面なのに対して、こちらは**数週間から1年分を横一列**で眺める画面です。スプリント単位で区切りながら、記録が濃い時期・薄い時期、案件の切り替わりを俯瞰します。

最初は「表示範囲を画面幅に押し込む」方式で作っていましたが、3つの問題が出ました。1日あたりの幅が極端に狭くなる、スプリントごとに幅を均等配分するので時間軸が非線形になる、日付単位に丸めるので時刻が失われる。

そこで**「1日 = Nピクセル」の連続した一次元スケール**に作り直しました。時刻から X 座標への変換は線形で、丸めません。30分の記録は30分ぶんの幅で描かれ、長いスプリントは長く描かれます。画面に収まらない分は横スクロールとズームで扱います。

## スケール

スケールは「原点の時刻」「終端の時刻」「1日あたりのピクセル数」の3つだけを持つ小さなクラスにして、時刻↔X座標の変換をそこに集約します。倍率は 8〜960 px/日の範囲で、既定は 120 です。

ズームはプリセット4つ（時間 480 / 日 120 / 週 40 / スプリント 12）とボタン（1.5倍ずつ）、Ctrl+ホイール（1.15倍ずつ）で変えます。**ホイールでは、カーソルの下にある時刻が動かないように**スクロール位置を補正します。これが無いと、拡大するたびに見ていた場所が画面外へ飛びます。

倍率はユーザー設定として保存しますが、ホイールは1回の操作で何度も発火するので、**600ms 待って落ち着いてから1回だけ**書き込みます。

## 行の詰め方

1アイテム1行にすると縦に間延びして、各行の横方向はほぼ空白になります。既定では**重ならないものを同じ行に詰めます**（日/週ビューの重なり計算と同じ貪欲法を、縦横を入れ替えて使います）。

このとき「重なり」の判定には、実際の終了時刻ではなく**描画幅・クリック判定幅・バーからはみ出すラベル幅**を時間に換算した終端を使います。ズームアウトして細くなったバーでも、隣のバーやその名前と重ならなくなります。ラベルぶんの予約には上限を設けて、長いタイトル1つで行が増え続けないようにします。

行のまとめ方は3つから選べます。詰める（既定）、カテゴリ別（カテゴリごとに行を分け、左に固定のラベル列を出す）、1件1行。

## 時間軸の文脈

バーだけを並べても、どこが何月なのか分かりません。次の要素を重ねます。

- **上段のルーラー**：スプリント名・期間・合計時間・上位カテゴリ。幅に余裕があるときだけ合計を出す
- **下段のルーラー**：ズームに応じて 3時間 → 日 → 週 → 月 と粒度が切り替わる目盛り
- **背景の日の列**：土日・無効曜日の薄い塗り、今日の強調、日境界の罫線（ズームアウト時は月曜だけに間引く）
- **現在時刻の赤い線**（30秒ごとに更新）
- **最下部の密度バー**：日別の記録時間を高さで示すヒートバー。個々のバーが読めない倍率でも「忙しかった時期」が分かります
- **範囲外インジケータ**：表示範囲の前後に記録が何件あるかを出し、押すとそこへ飛びます

ルーラーと密度バーは本体とは別のスクロールなので、横スクロール位置をコードビハインドで同期させます。

## 軽さのための2つの工夫

Canvas は仮想化しません。最大25スプリント（約525日）を最大ズームで表示すると、目盛りだけで数千個の要素になります。そこで**見えている範囲の前後1画面分だけを実体化**し、その窓の内側にいる限りは作り直しません（ヒステリシス）。通常のスクロールでは数回に1度しか再構築が起きません。

もう1つはドラッグ中です。バーを動かしている間は時間軸そのものは動かないので、**目盛り・背景・密度バーは作り直さず、行の割り当ても変えません**。掴んだバーが移動のたびに別の行へ飛ぶと狙った位置に置けませんし、毎フレーム数百要素を作り直すと引っかかります。確定したときにまとめて組み直します。

## 操作

バーは、幅が十分あるときだけ両端がつまみ（伸縮）になり、それ以外は移動です。細いバーは常に移動として扱います。スナップ単位は設定値をそのまま使うのではなく、**ズームが粗いときは粗く**します（1日が20px しかないときに15分刻みで動かしても操作できません）。

空き領域を横にドラッグすると、その期間で新規作成。キーボードは、←→で選択の移動、Enter で編集、Delete で削除、F で選択中のアイテムに合わせてズーム、T または Home で今日へ、Ctrl+±でズーム、Ctrl+D/C/V で複製・コピー・貼り付けです。

検索中は、ヒットしないバーを薄く落として目的のものを浮き上がらせます。バーの座標は変えずに、透明度のプロパティだけを更新してください（リストを作り直すと重い）。
