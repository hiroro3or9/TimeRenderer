# 05. 日/週ビューと予定の編集

このアプリで一番よく使う画面です。時間軸を縦に取り、日ごとに列を分けます。

## 表示する範囲

表示する時間帯は設定で変えられます（既定は 0時〜24時）。縦のスケールは 1時間 = 60px 固定で、時間帯を狭めると画面に収まる密度が上がります。

表示する曜日も設定で選べます。土日を外している人にとっては、空の列が2つあるだけで平日の幅が狭くなるからです。週ビューは月曜始まりで、有効な曜日だけを列にします。

日付の前後移動は、日ビューなら1日、週ビューなら1週間ずつ。移動の向きをスライドアニメーションの方向に渡します。

## レイアウトの計算

1回の再計算で次を作ります。

1. 表示フィルタを通り、表示範囲に重なるアイテムだけを拾う
2. 終日のものは終日行へ、そうでないものは時間グリッドへ振り分ける
3. 日をまたぐアイテムは**日ごとのセグメントに切り分ける**（週ビューで列をまたいで描けないため）
4. 同じ日の中で時間が重なるものに列番号を割り当てる
5. 月/スプリントビュー用のセル、タイムライン用のバー、統計、未記録の帯、今日ホームの要約も同じタイミングで作り直す

重なりの列割り当ては、時間順に見て「今の塊と重なっているか」を判定し、重ならなくなったところで塊を閉じる、という素直な方法です。塊の中で使える一番若い列に入れ、塊全体の列数を全員に配ります（同じ塊なら同じ幅になる）。この計算は純粋関数にしてテストを書いてください。

## 画面の組み立て

左に時刻の目盛り、上に曜日ヘッダー、その下に終日行、残りが時間グリッドです。時間グリッドは Canvas の上にアイテムを絶対座標で置きます。

背景には1時間ごとの罫線、今日の列の薄い塗り、現在時刻の横線を描きます。アイテムより先に描いて背面にしてください。

予定バーは角丸の矩形で、**実績は塗り、予定は薄い塗り＋2pxの枠線**にします。選択中はさらに太い枠。日をまたぐアイテムだけは L 字の図形で描き、翌日側に少しはみ出させて「続いている」ことを示します。

終日イベントは上の行に横長の帯として積み、期限のある ToDo はその下にピル型のチップとして並べます。予定と ToDo を同じ見た目にしないでください（片方は時間の予約、もう片方はまだ手が付いていないこと）。

未記録の帯（記録漏れの候補）は破線の枠だけで薄く敷き、**左クリックは受けずに背景へ透過させます**。帯の上で空白ドラッグ＝新規作成ができることが、そのまま穴埋めになるからです。右クリックだけは帯が受けて、埋め方のメニューを出します。

出退勤は横線とラベルで表し、ラベルをクリックすると勤務時間の編集が開きます。

## ドラッグ操作

バーの上端・下端（8px）をつかむと伸縮、それ以外は移動です。4px 動かすまではドラッグと見なしません（クリックでの選択を邪魔しないため）。

時刻は設定の刻み幅（既定15分）に丸めます。さらに**マグネット**として、隣の予定の端・出退勤の線・現在時刻の近く（6px 以内）に来たら吸い付かせ、吸い付いたときだけ細いガイド線を出します。会議の直後に作業を置く、といった操作が一発で決まります。

**Alt を押しながら**だと丸めも吸着も外れて1分単位になります。同時に、ドラッグ開始時に Alt を押していれば「複製して移動」になります。

ドラッグ中は再計算だけを行い、保存も履歴も触りません。確定（マウスアップ）したときに初めて、開始前の状態と現在の状態を1件の履歴として積み、保存します。

## 空き領域の操作

- 縦にドラッグ：その時間帯で新規作成
- ダブルクリック：その時刻から既定の長さで**インライン作成**（小さなテキストボックスがその場に出る）
- 右クリック：貼り付けなどのメニュー
- ToDo をドロップ：その時刻に ToDo の時間ブロックを置く

インライン作成では、Enter で確定、Ctrl+Enter で確定して続けて次を作る、Esc で取り消しです。確定するまで履歴には積みません。作られるアイテムの種別は、**終了時刻が現在より前なら実績、そうでなければ予定**にします。過ぎた時間に書くのはたいてい「やったことの記録」だからです。

## キーボード

選択中のアイテムに対して、Enter で編集、Delete で削除、Ctrl+D で複製、Ctrl+C / Ctrl+V でコピーと貼り付け、矢印キーで移動（Shift と組み合わせると伸縮）。Ctrl+Z / Ctrl+Y は全画面共通です。

## 編集ダイアログ

追加と編集で同じダイアログを使います。上部に「予定 / 実績」のセグメントを置き、選んだ種別で見出しの文言と入力欄の出し分けが変わります（実績と終日予定には「開始時の動作」がありません）。

入力するのはタイトル（定型タイトルと直近1か月の履歴から候補を出す編集可能なコンボ）、内容、開始・終了の日時、終日チェック、カテゴリ、プロジェクトコード、そして予定のときだけ「開始時刻に通知する」「自動で記録を開始する」「記録中でも強制的に開始する」です。

時刻は分を1分刻みで選べるようにし、**秒は元の値を保ちます**。ドラッグで作った 10:03:27 のような時刻を、ダイアログを開いただけで丸めてしまわないためです。

検証はその場でメッセージを出します（タイトル未入力、終了が開始以前、日付未選択など）。OK を押したら新しいインスタンスを返し、呼び出し側が既存アイテムへ**値を書き戻します**。インスタンスごと差し替えると、そのアイテムを参照している選択状態や履歴が切れます。
