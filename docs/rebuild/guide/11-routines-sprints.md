# 11. スプリントと定期予定

## スプリント

スプリントは「2週間」のような作業の区切りで、カレンダーとタイムラインの表示範囲、統計の集計期間として使います。

手動で登録したスプリントを基準にして、**登録していない期間は14日単位で自動的に埋めます**。手動が1件も無ければ決め打ちの基準日（2026年最初の月曜）から数えます。過去方向にも自動で伸ばし、自動で作ったものは名前に「(自動)」を付けて区別します。手動のスプリントの直前で自動スプリントを打ち切るので、登録した期間がずれることはありません。

この計算は表示のたびに何度も呼ばれるので、前後3か月ぶんをキャッシュします。

登録は管理パネルから行い、名前・開始日・終了日を入れます。既存のスプリントと期間が重なっていれば弾きます。新規登録のときは、最後のスプリントの翌日から2週間を初期値として入れておきます（たいていそれで合っているため）。

## 定期予定

「毎週月曜 10:00-10:30 の朝会」のようなテンプレートから、予定を自動生成します。

### 生成の考え方

生成された予定は、はじめは**仮想アイテム**です。ファイルには保存せず、表示のたびにテンプレートから作り直します。前後の一定期間（過去7日〜先60日）だけを作り、既に実体として存在する日は飛ばします。

ユーザーがその予定に触った瞬間（編集・ドラッグ・記録開始・削除）に**実体化**します。実体化と同時に、テンプレート側の「除外日」にその日を追加します。こうしないと、次の再生成でもう1つ同じ予定が現れます。

この方式のおかげで、テンプレートを変えると未来の予定が全部追随し、個別に直した日はそのまま残ります。

### 範囲の確認

仮想アイテムを編集・削除・ドラッグしたときは、「この日のみ」「定期予定全体」「キャンセル」を聞きます。全体を選んだときはテンプレートを書き換え、この日のみならその日だけ実体化します。日をまたぐ時間帯は定期予定全体には設定できないので、その場合はメッセージを出して断ります。

この操作は**取り消し履歴には積みません**。テンプレート（設定）の変更なので、予定の履歴と同じ軸で戻せると混乱します。

### 繰り返しの種類

曜日指定（毎週・N週ごと）、日付指定（毎月N日・Nヶ月ごと）、第N曜日指定（第1・第3月曜、最終金曜）の3つです。加えて「N回に1回休む」を指定できます（隔回の当番など）。

判定で気を付ける点が3つあります。

- **N週ごとの起点は開始日を含む週**。週番号は月曜始まりで数えます
- **存在しない日は末日へ繰り下げる**。2月30日の指定は2月28日（または29日）になります
- **第5週が無い月は飛ばす**。毎月必ず入れたいなら「最終」を選ばせます

「N回に1回休む」は、開始日以降の何回目かを数える必要があります。休んだ回も回数に数えます。

### 通知と自動開始

開始時刻になったら、テンプレートの設定に応じて通知するか、記録を自動で開始します。自動開始は既定では「他の記録が走っていなければ」動き、「記録中でも強制的に開始する」を選ぶと、走っている記録を停止・保存してから始めます。

判定はセッション内で1回だけ行い、**15分以上遅れて気づいたものは出しません**（起動しただけで朝の通知が全部出てくるのを防ぐため）。通知には「記録開始」ボタンを付けて、ワンクリックで始められるようにします。

### 編集ダイアログ

繰り返しの種類によって出す入力欄を切り替えます（曜日／日付／第N週＋曜日）。間隔・開始日・休みの設定・開始終了時刻（5分刻み）・カテゴリ・プロジェクトコード・自動開始の挙動・有効/無効。

それぞれの入力の下に、迷いやすいところの説明を1行添えます（「間隔の起点は下の開始日です」「第5週が無い月は飛ばします」など）。この手の設定は、後から見て自分でも意味が分からなくなるのが一番多い失敗です。
