# 09. ToDo

## 予定との違い

予定は「いつやるか」が決まっているもの、ToDo は「やること」そのものです。期限を持つものだけが日/週ビューの終日行と月のセルに並びます。ToDo から記録を始めると、停止したときにその ToDo へ時間が積算されます。

置き場所は右のパネルです。開閉は設定に保存し、他のパネルとは排他です。

## 思いついた瞬間に置けること

一番大事なのは、追加が速いことです。パネル上部の1行入力に打って Enter を押すだけで追加され、欄は空に戻ります。期限も優先度も後から付けられます。

それでも「明日までの高優先度」くらいはその場で指定したい、という要求に応えるのが**クイック追加の記法**です。

```
資料作成 @明日 !高 #開発 ~30m *前日
```

`@` が期限、`!` が優先度、`#` がカテゴリ、`~` が見積もり、`*` が通知です。`@` は「明日」「来週」「+3d」「8/20」「金」などを受け、全角の記号（＠！＃〜＊）も受けます。日本語入力のまま打てないと、そもそも使われないからです。

記法には2つの制約があります。**記号は行頭か空白の直後でしか効きません**。これが無いと「9時〜10時 打ち合わせ」の `〜` が見積もりに、「腕立て*30回」の `*` が通知に化けます。そして**解釈できなかった記号はそのまま本文に残します**。消えるより残るほうが安全です。

入力中は欄の下に解釈結果（「資料作成 ／ 期限 8/21(木)・優先度 高・カテゴリ 開発・見積もり 30分」）を出します。これが無いと、記号が効いたのかただの文字になったのかが Enter を押すまで分かりません。記法そのものは設定でオフにできます。

## 一覧の見せ方

1行に、カテゴリ色の縦帯、チェック、タイトル、期限チップ、通知・繰り返し・優先度・進捗の小さな印を詰めます。ホバーすると行が持ち上がり、右端に「この ToDo で記録開始」ボタンが現れます。

完了は**チェックボックスではなくボタン**にします。双方向バインドだと「変更前の状態」を掴めず、取り消し履歴に積めないためです。完了すると取り消し線と灰色にして、残っているものと区別します。

期限は超過なら赤、今日なら橙。見積もりがあれば「実績 / 見積もり」と進捗バーを出し、超過したら警告色にします（バー自体は満杯で止めます）。サブタスクがあれば進捗と展開の三角を出し、開くとその場で追加・完了・削除ができます。

並べ替えは期限順・優先度順・追加順・手動の4つ。どのモードでも「未完了が先」「今日やる印が先」は共通です。手動を選ぶと、ドラッグと Ctrl+↑↓ で並べ替えられます。手動以外のモードから並べ替えを始めたら、**今見えている順を確定してから**手動へ切り替えます（そうしないと最初の1回で順序が飛びます）。

## 期限・今日やる・繰り返し

期限は日付だけを持ちます。時刻まで決めたいものは、ToDo ではなく予定にすべきだからです。

それとは別に「今日やる」という印があります。期限は来週でも今日手を付けると決めたもの、という意味です。この印は真偽値ではなく**日付**で持つので、日をまたぐと自動的に外れます。ただしそのままだと、手を付けなかったものが黙って消え、「決めたのにやらなかった」ことが残りません。そこで**退勤時のふりかえりで明日へ送るかを聞きます**（`10`）。

繰り返しは「完了したときに次回分を作る」方式です。作られた次回分は、タイトル・カテゴリ・見積もり・サブタスクの手順を引き継ぎ、完了状態だけ外れます。**完了した側の繰り返し設定は解除します**。付けたままだと、同じものを何度も完了させるたびに次回分が増え続けます。次回分ができたことは通知で知らせます。

## 通知

ToDo ごとの通知日時は、絶対日時でも「期限の前日 9:00」のような相対指定でもかまいません。相対にしておくと、**期限を動かしたときに通知も一緒に動きます**。

通知時刻を過ぎたらカードを出し、音を鳴らします（設定で消せます）。ただし遅れて気づいた通知を全部出すと邪魔なので、**15分を超えて遅れたものは個別のカードにせず「見逃した通知」として1本にまとめます**（3日より前のものは捨てます）。「あとで」を押すと指定時間だけ先送りし、そのとき相対指定は外します。

これとは別に、1日1回の**朝のまとめ**があります。設定した時刻を過ぎて最初に使ったときに、「今日が期限の ToDo が3件、期限を過ぎた ToDo が1件あります」と出します。個別の通知を付け忘れていても、その日に片付ける量が一度は目に入るようにするためです。0件の日は出しません。

## 見積もりと積みすぎの検知

完了した ToDo のうち、見積もりと実績が両方あるものから「見積もりに対して実際どれだけかかったか」の比を集めます。カテゴリごとに3件以上あればカテゴリ別、無ければ全体の中央値を使い、編集ダイアログで見積もりを入れるその瞬間に「これまでは見積もりの約1.3倍かかっています（8件）」と出します。

同じ材料を使って、**今日の負荷**も出します。「今日やる」の見積もり残を実績比で補正した合計と、いつもの退勤時刻（自分で押した退勤の中央値。5件以上たまってから）までの残り時間を比べ、超えていたら色を変えます。止めはしません（毎朝止められると読まなくなります）。

## 記録・予定との連動

ToDo は3つの経路で時間とつながります。

- **記録開始**：ToDo のタイトル・色・カテゴリで記録を始め、停止時に実績と積算を作ります
- **時間ブロック**：ToDo を日/週ビューへドロップすると、見積もり（無ければ1時間）の長さの予定になります
- **記録漏れの穴埋め**：未記録の帯を右クリックして ToDo を選ぶと、その時間の実績になり積算されます

どれも取り消し履歴に1件として積みます。実績の追加と ToDo の積算は**必ず同じ1件**にまとめてください。別々だと Ctrl+Z 1回で片方だけ戻り、数字が合わなくなります。

## 片付け

完了した ToDo は一覧から隠せますが、消しはしません。設定した日数（既定90日）を過ぎたものは起動時に**アーカイブファイルへ移します**。一覧からは消えますが、見積もりの傾向の集計には引き続き使われます。

「完了済みを削除」もありますが、まとめて1件の履歴に積んで Ctrl+Z で戻せるようにします。

## 編集ダイアログ

タイトル、期限（「今日」「明日」「なし」のボタン付き）、優先度、見積もり、繰り返し、カテゴリ、通知、サブタスク、メモ。縦に長いので、この画面だけは入力欄を詰めて並べます。

通知のタイミングは「日時を指定」と「期限の当日/前日/2日前/3日前/1週間前」から選び、相対を選んだときは日付ピッカーの代わりに計算結果の日付を出します。期限が無いときは相対を選べません（基準が無いため）。

OK を押したら、既存の ToDo の Id・作成日時・記録済み時間・並び順・完了状態を引き継いだ新しいインスタンスを返し、呼び出し側が値を書き戻します。
