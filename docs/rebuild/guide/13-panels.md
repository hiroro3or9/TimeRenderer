# 13. 設定パネルと管理パネル

右端に開くオーバーレイが2枚あります。分け方の基準は、**設定パネル＝アプリの振る舞い**、**管理パネル＝データのマスター**です。「カテゴリを追加する」は設定ではなくデータの追加なので管理側、という切り分けです。

どちらも幅は固定（設定400px、管理440px）、0.15秒で伸縮し、他のパネルとは排他です。中身は固定幅にしておきます（縮むアニメーションの途中で中身が折り返さないように）。

## 設定パネル

上にヘッダー、その下に検索ボックス、残りがスクロールする本文です。本文は折りたたみセクションの並びで、**既定では全部閉じています**。

セクションは8つ。

1. **外観** … ダークモードのトグルスイッチ
2. **表示設定** … 表示時間範囲、時刻の刻み幅、隣の予定への吸着、表示曜日
3. **記録中のミニバー** … 出すかどうかと、その説明
4. **離席・中断の検知** … 検知するか、離席とみなす時間、検知したときの扱い
5. **使用アプリの記録** … 収集するか、何をどこに残すかの説明
6. **Git のコミット履歴** … 使うか、リポジトリの登録一覧、状態の一文
7. **ToDo** … クイック追加の記法、通知（既定時刻・あとでの時間・音）、朝のまとめ、完了済みを残す期間
8. **勤務の記録** … 終了の検知、確認する時間帯、退勤時のふりかえり

どのセクションも、項目の下に**何が起きるかを1〜3行で説明**します。この手の設定は名前だけでは意味が伝わらず、説明が無いと結局触られません。「常に除外する」を選ぶと確認なしで差し引く、その内容は通知され Ctrl+Z で戻せる、といった具合に、**結果と取り消し方**まで書いてください。

表示時間範囲と表示曜日は、日/週ビューなど関係する画面を見ているときだけ出します。離席や勤務の詳細設定は、親のチェックが入っているときだけ出します。

### 検索

設定が増えると目的の項目に辿り着けません。検索ボックスに打つと、セクション単位で絞り込みます。セクションごとにキーワードの配列（「離席」「中断」「無操作」「スリープ」「ロック」「除外」など）を持たせ、入力との**双方向の部分一致**で判定します（「通知」で ToDo が出る、「つうち」では出ない、程度の素朴さで十分です）。

一致したセクションは自動的に開き、どれも一致しなければ「該当する設定がありません」と出します。検索を消したときに閉じ直さないのは、探し当てた項目をそのまま触りたいからです。

## 管理パネル

タブが3つ（分類 / 定期予定 / スプリント）あります。

### 分類タブ

**カテゴリ**は、色のコンボ（16色のパレットから選ぶ）・名前・削除ボタンの行が並びます。名前はフォーカスが外れたときに確定します（1文字打つたびに保存とレイアウト再計算が走らないように）。追加すると、まだ使っていない色を優先して割り当てます。最後の1件は削除できません。削除しても、その色を使っている既存の記録は残ります。

その下に「記録開始時の既定カテゴリ」を置きます。

**プロジェクトコード**は、コード・名前・有効/無効の切り替え・削除。予定や定期予定で使われているコードは削除できず、その旨を出します。有効なコードが1件だけのときは無効化も削除もできません。ここに「既定のプロジェクトコード」と、未記録時間を集計に含めるかどうか・その加算先・期間ごとの加算先（`08` 参照）も置きます。

期間ごとの加算先は「この日から」の行を足していく形で、行の下に期間の表示（「2026/01/05 〜 2026/02/01」）を出します。後ろの行に上書きされて一日も受け持たない行は、黙って消えると気づけないので「（次の行に上書きされます）」と出します。

**定型タイトル**は、タイトル入力欄の候補に常に出す文字列の一覧です。

### 定期予定タブ / スプリントタブ

どちらも同じ形のカード一覧です。定期予定は「タイトル／繰り返しの説明と時間帯／自動開始・無効の印」と編集・削除ボタン。スプリントは「名前／期間」と編集・削除ボタン。下に追加ボタンを置き、スプリントの追加だけはその場に入力フォームを展開します（項目が3つしかないのでダイアログにするほどではない）。

削除は、影響が残るもの（カテゴリ・スプリント・定期予定）だけ確認を出します。リポジトリの登録解除のように、消しても記録が一切変わらないものは確認しません。
