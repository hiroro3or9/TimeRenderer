# 03. 見た目の作り方

## 色は名前で呼ぶ

配色は「トークン」と呼ぶ名前付きの色で定義し、画面からは常に `{DynamicResource トークン名}` で参照します。直接 `#RRGGBB` を書いてよいのは、テーマに関係なく同じであるべきもの（記録中の赤いバッジ、現在時刻ラインの赤、コンボの色見本の枠など）だけです。

トークンは用途で名前を付けます。

- 面：背景（アプリの地）、サーフェス（カードや一覧の地）、抑えた背景（ヘッダーや日付ラベル）
- 文字：主・副・さらに薄い補助
- 線：境界線、ホバー時の境界線
- 強調：プライマリ（青系）とその薄い版、危険（赤系）とその薄い版・濃い版
- 操作：ホバー地、押下地
- 機能ごと：ToDo の期限超過・今日・優先度高、未記録の帯の塗りと破線

ダークテーマは**同じ名前のトークンを別の値で定義した辞書**を作り、リソースの末尾に足す/外すだけで切り替えます。画面側は何も変えません。各ビューを作るときは、必ず両方のテーマで一度見てください。トークン経由になっていない箇所は、ダークにした瞬間に白い箱として浮き上がります。

## スタイルは先に全部作る

ボタンや入力欄のスタイルは、最初のフェーズで**一式まとめて定義**しておきます。以降の画面は「このスタイルを使う」と指定するだけになり、画面ごとに見た目がばらけません。

用意するのは次の系統です。

- **ボタン**：標準（枠線あり）、プライマリ（塗り）、ゴースト（枠なし・ホバーで薄く色が付く）、アイコンボタン（正方形・文字だけ）、トグル
- **セグメント**：左・中・右で角丸の付き方が違うラジオボタン。ビューの切り替えや優先度の選択に使う
- **ナビゲーション**：選択中に下線と色が付くタブ的なボタン
- **通知カード**：角丸・薄い背景・アイコンと本文とボタンが1行に並ぶ
- **入力**：テキストボックス、コンボボックス、スクロールバー（アニメーションなしの細身）
- **パネル用**：折りたたみセクション、セクション見出し、タブ
- **その他**：統計の棒、ToDo のチェックボタン、タグのチップ、ふりかえりのカード、検索結果の行

ゴーストボタンだけは、背景色をトークンではなく固定値で持っています。パネル内の淡い背景の上で押せることを示すのに、テーマのホバー色では弱すぎたためです。

## コンバーターの役割

日/週ビューは Canvas 上の絶対座標で描くので、時刻や日付から座標へ変換するコンバーターが要ります。

- 時刻 → 縦位置（表示開始時刻を引いて、1時間=60px で掛ける）
- 所要時間 → 高さ
- 日付 → 横位置と幅（週ビューなら「その日が何列目か」、重なりがあれば列番号で分割。終日行は別扱い）
- 日付 → そのページに表示するかどうか（前後の日のページを裏に持っているため）
- 日跨ぎのアイテム → L字の形（下端から翌日の上端へ折り返す図形）

このほか、色から文字色を決めるもの（背景が明るければ黒、暗ければ白）と、色を薄めた背景を作るもの（予定を実績より目立たせないため）があります。どちらも計算結果をキャッシュしてください。1フレームで何百回も呼ばれます。

縦のスケールは**1時間 = 60px** で、この数値は定数クラス1か所にだけ書きます。

## 画面切り替えのアニメーション

日付を送ったりビューを切り替えたりしたとき、内容が横（または縦）にスライドして入れ替わるようにします。前の内容と新しい内容を一時的に重ねて、300ms で滑らせるコントロールを1つ自作します。方向は ViewModel が「進む/戻る」を持っていて、それに従います。

中ボタンドラッグでのオートスクロール（一覧を素早く流し読みするため）も、添付プロパティ1つで各 ScrollViewer に付けられるようにしておきます。

## アイコン

アイコンは画像ではなく `Segoe MDL2 Assets` フォントのグリフを文字として置きます。検索・追加・ピン・チェック・時計・ベル・繰り返し・再生・展開の矢印など、十数種類しか使いません。

アプリアイコン（ico）だけはこのキットに含まれていません。トレイ用にはさらに、そのアイコンへ「出勤中（左下の緑の点）」「記録中（右下の赤い丸）」を重ねた状態アイコンを実行時に描き起こします。サイズに応じて半径や縁の太さを比率で決めておくと、小さいサイズでも潰れません。
