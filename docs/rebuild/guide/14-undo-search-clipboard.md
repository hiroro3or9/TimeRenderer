# 14. 取り消し・検索・コピー

## 取り消し/やり直し

このアプリでは、**予定と ToDo の変更を1本の履歴**にまとめます。パネルごとに履歴を分けると、「さっきの操作」がどちらの履歴にあるか人間が覚えていないといけません。Ctrl+Z は常に「最後にやったこと」を戻すべきです。

履歴に積むのは「戻す方法」と「やり直す方法」を持った小さなオブジェクトです。種類は、アイテムの追加・削除・変更、ToDo の追加・削除・変更・並べ替え・積算時間の変更、そして**複数をまとめて1件に見せるもの**。

原則が2つあります。

- **復元は必ず元のインスタンスへ書き戻す**。新しいインスタンスで置き換えると、そのアイテムを参照している選択状態・ドラッグ中の対象・別の履歴項目が切れます
- **1つの操作は1件**。ドラッグ（移動と長さの変更）、記録の停止（実績の作成＋ToDo への積算）、繰り返し ToDo の完了（完了＋次回分の作成）などは、内部では複数の変更でも履歴上は1件にします

適用中は専用のフラグを立て、変更ハンドラからの再計算・保存・履歴追加をすべて止めます。適用が終わったら、まとめて再計算と保存を1回だけ行います。

履歴の上限は100件です。ボタンのツールチップには「元に戻す: ToDo「資料作成」の完了」のように**何が戻るか**を出します。これが無いと、押していいかどうかが分かりません。

キーは Ctrl+Z と Ctrl+Y（Ctrl+Shift+Z も同じ）。テキストボックスにフォーカスがあるときは、そちらの編集の取り消しを優先します。

## 選択

選択状態はアイテム自身が持ちます。日/週・月・タイムラインのどこで選んでも同じ状態を指すようにするためです。選択を変えたときに画面をスクロールさせるかどうかは**呼び出し側で決めます**。クリックで選んだときに表示が動くと、掴もうとした対象がカーソルの下から逃げます。キーボードで選択を移したときや、検索結果から飛んだときだけ、見える位置まで寄せます。

## 複製・コピー・貼り付け

Windows のクリップボードは使わず、アプリ内に1件だけ保持します。他のアプリとテキストをやり取りしたいわけではなく、予定の構造をそのまま持ち回りたいからです。

複製（Ctrl+D）は同じ内容を少しずらして作り、コピー（Ctrl+C）は控えるだけ、貼り付け（Ctrl+V）はマウス位置や表示中の日の同じ時間帯に置きます。複製するときは、Id と「どこから来たか」の紐づけ（定期予定・元の予定・ToDo）を**引き継ぎません**。コピーした予定が元の定期予定の一部として扱われると、片方を消したときにもう片方が道連れになります。

## 検索

ツールバーの検索は、予定・ToDo・ふりかえりを**1つの一覧に混ぜて**返します。探すときに「これは ToDo だったか予定だったか」を先に思い出せることは少ないからです。

行には種別・日付・タイトル・補足（時間帯や期限）を出し、選ぶとその日付へ移動して対象を選択（ToDo ならパネルを開いて選択）します。タイムラインを見ているときは、ヒットしないバーを薄く落として目的のものを浮き上がらせます。

## 表示フィルタ

カテゴリとプロジェクトコードごとの表示/非表示です。検索と違い、**表示そのものを絞ります**。解決できない（カテゴリ未分類・コード未設定の）アイテムは常に表示します。消えたことに気づけないからです。

この状態は**保存しません**。次に起動したときは全部見える状態から始めます。絞り込んだまま忘れて「予定が消えた」と勘違いするのを防ぐためです。ToDo パネルにもフィルタは効かせません（パネルは「やることの全体像」なので）。
