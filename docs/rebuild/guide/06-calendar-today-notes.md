# 06. 月/スプリントカレンダー・今日ホーム・ふりかえり一覧

## 月とスプリントは同じグリッド

月ビューとスプリントビューは同じ UserControl を使います。違うのは行数（月は6週固定、スプリントは期間の週数）と、「今の期間の内か外か」の判定だけです。スプリントは開始日の週の月曜から終了日の週の日曜までを敷き詰めます。

上に曜日ヘッダー（土は青系、日は赤系）、下にセルを敷きます。セルの中身は、上から予定・実績、その下にその日が期限の ToDo です。日/週ビューの終日行と同じ並びにして、ビューを切り替えても位置関係が変わらないようにしています。

## セルは自前で描く

セルを普通のパネルとテキストで組むと、6週×7日×数件で要素数が跳ね上がります。ここだけは `FrameworkElement` を継承して **`OnRender` で直接描きます**。

描く順番は、背景（今月でなければ薄いグレー、今日なら薄い青）、日付の数字、そして行です。行は高さ18pxで、入りきらなければ最後の1行を「+3 件」に差し替えます。

予定は薄い塗りに細い枠、実績は塗り、ToDo は塗らずに枠線だけのピル型（期限超過なら赤、優先度高なら枠を太く）。**塗りつぶしの箱と枠だけの箱で、済んだことと未着手を見分けられる**ようにしています。

自前描画にすると当たり判定も自分で書くことになります。描画とヒットテストで**同じレイアウト計算・同じ DPI 値**を使ってください。別々に書くと高 DPI 環境でクリック位置がずれます。

操作は、ダブルクリックで編集（予定なら予定の編集、ToDo なら ToDo の編集、空白なら新規作成）、右クリックで予定のメニューです。シングルクリックで開かないのは、カレンダー上ではクリックしながら日を追う動きが多いためです。

## 今日ホーム

起動直後に開く画面です。「いま何をしているか／次に何をするか」を最初に見せ、その下に今日の数字、さらに下に予定と ToDo の一覧を並べます。

先頭のカードは3状態あります。記録中なら記録中のタイトルと経過時間と停止ボタン、記録していなくて次の予定があるならその予定と「記録開始」、どちらも無ければ「次の予定はありません」と次の一手の案内。

その下に4つの指標を並べます。今日の実績の合計、予定の合計、未記録の合計（件数付き）、そして「今日の負荷」（今日やる ToDo の見積もり残と、いつもの退勤時刻までの残り時間の比較。`09` 参照）。

さらに下は左右2枚のカードで、左が今日の予定（時間・タイトル・カテゴリ・「開始」ボタン。次の予定には印を付ける）、右が「今日やる」ToDo（進捗・期限・「開始」「完了」）。最後に日ビューへ飛ぶボタンを置きます。

この画面の材料は、レイアウト再計算・未記録の帯の更新・負荷の計算・分が変わったときのそれぞれから作り直します。

## ふりかえり一覧

退勤時に書いた「今日のひとこと」を、**全期間まとめて新しい順に**読み返す画面です。統計にも同じ内容を出していますが、あちらは週/月/スプリントの区切りに縛られるので、「いつ書いたか覚えていないものを探す」には使えませんでした。

日付では絞らず、月の見出し（「2026年8月」＋件数）を挟んで並べます。件数が増えてもスクロール位置で時期が掴めます。1件ずつはカードで、日付・その日の勤務時間帯・本文、そして本文に含まれるタグを出します。カードを押すとその日の勤務記録の編集が開き、そのまま書き直せます。

本文の中の `#タグ` は正規表現で拾います。タグ専用の入力欄を作らないのは、書く場所が増えるほど書かなくなるからです。**本文からタグを取り除かずそのまま保存**します（書いた文章と保存された文章が食い違うのは気持ちが悪い）。

一覧の上にタグのチップを件数の多い順で並べ、押すと絞り込み、もう一度押すと解除。チップは**絞り込む前の全件**から作ります。絞り込むたびに他のタグが消えると、そこから別のタグへ移れません。絞り込み中のタグが本文の書き換えで消えたときは、黙って絞り込みを解除します。

1件も無いときは、空の一覧ではなく「どこで書くものなのか」を案内します。
